# OsdagBridge Testing – FOSSEE Screening Task

Functional testing of the OsdagBridge short-span steel girder module (Windows 11, 4 GB RAM, branch `dev`).

## Contents
- `osi/` – saved input files for every test case
- `results/` – Results Table exports (input and output tables)
- `reports/` – design report PDFs
- `screenshots/` – evidence screenshots
- Test report PDF, issue links and video link: see the submission form

## Test cases
TC1 baseline (30 m / 7.5 m) · TC2 (45 m / 12 m) · TC3 (median + footpath) · TC4 (TC1 repeat) · TC5 · Run 1–3 (custom materials E 300A / M30, consecutive runs) · N1a–g (invalid inputs)
